# Referencias de marca

Durante la migración inicial no había referencias visuales accesibles. Posteriormente se localizaron dos conjuntos de activos, conservados intactos en [`recovered-assets/`](recovered-assets/README.md) junto con su inventario técnico y hashes.

Estos archivos son material recuperado, no una aprobación automática. Cada referencia debe indicar su procedencia y si sirve como contexto, candidata o fuente autorizada. Una referencia no equivale a una decisión aprobada y nunca debe sustituir a un SVG maestro.
