# Logo — maestros pendientes de validación

No hay todavía SVG confirmados como maestros oficiales dentro de esta carpeta. La estructura espera exactamente:

- `lugazgo-primary.svg` — logotipo principal auténtico;
- `lugazgo-symbol.svg` — símbolo auténtico;
- `favicon.svg` — favicon auténtico.

Se localizaron 16 SVG y 3 exportaciones PDF fuera de esta carpeta. Se conservaron, sin renombrar ni modificar, en [`../references/recovered-assets/`](../references/recovered-assets/README.md). Hay dos composiciones distintas del logotipo, dos estructuras equivalentes del símbolo y varias opciones de favicon; por eso no se ha elegido un mapeo por inferencia.

## Cómo incorporarlos

1. Validar la procedencia y precedencia de los activos recuperados.
2. Confirmar expresamente qué archivo corresponde a cada maestro canónico.
3. Copiarlos aquí sin alterar trazados, proporciones, colores ni metadatos relevantes, conservando los originales recuperados.
4. Si los nombres originales difieren, conservarlos hasta registrar el nombre definitivo o el mapeo en `docs/decisions.md`.
5. Registrar la procedencia y la incorporación en `docs/decisions.md`.

No crear sustitutos falsos, reconstrucciones aproximadas ni archivos vacíos con extensión `.svg`.
